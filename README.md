# RECON

Quiz photo pour apprendre à identifier les véhicules et armes militaires (chars, artillerie, génie, pièces débarquées).

Application web installable (PWA) : ouvrir le site sur le téléphone puis « Ajouter à l'écran d'accueil ».

Photos : Wikimedia Commons (licences libres, auteur et licence indiqués sur chaque fiche) et photos fournies par l'utilisateur.
